## 目标与范围

推断目标：在上游已完成身份与权限校验的前提下，修改或解绑用户安全资料，并记录操作。
本函数本身不足以证明上游授权条件，需要结合调用方确认谁可以触发重置。

主要依据：`app/business/security.py` · `reset_security_info`。

## 已实现规则

### SEC-01 · 提现密码重置

当重置类型为 WITHDRAW_PASSWORD 时，调用用户扩展信息的提现密码重置方法，记录操作日志与安全工具历史，然后提前返回。

这意味着该分支不会执行本函数末尾的通用登录态清理与默认安全工具更新。这里只描述当前代码，不推断该行为是否满足产品预期。

### SEC-02 · TOTP、WebAuthn 与手机号解绑

- TOTP 分支清除 TOTP key，记录操作与安全工具历史。
- WebAuthn 分支调用用户 WebAuthn 删除方法并记录历史。
- 手机号分支清除号码，历史记录保留原号码信息。
- 这些分支继续进入后续通用登录态清理流程。

### SEC-03 · 邮箱修改

- 更新用户邮箱。
- 遍历邮箱验证码类型，删除旧邮箱对应缓存。
- 写入邮箱修改日志与安全工具历史，历史中记录旧邮箱。
- 新邮箱格式与所有权验证需查调用入口，本函数片段不足以确认。

### SEC-04 · 通用登录态清理

除提前返回的分支外，代码清理用户登录 token 缓存，并将返回的 token 传给用户登录状态清理方法；有 token 时记录退出日志。随后调用默认安全工具更新函数。

这不自动证明所有端和外部服务会话已失效，需要查清相关缓存及会话验证链路。
