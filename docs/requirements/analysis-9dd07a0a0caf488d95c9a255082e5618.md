### 3. 请求锁不等于订单幂等

API v2 展示的顺序是**先创建订单，再保存 `client_id` 映射**；这段提交逻辑没有按 `client_id` 查重。模型中的 `(user_id, client_id)` 索引也未声明 `unique=True`。因此，现有片段不足以证明同一 `client_id` 重试不会重复建单。[app/api/v2/assets/swap.py:202](/api/sources/6eb7365e06210b01f166cc96)[app/models/mongo/exchange.py:7](/api/sources/3133070f84bd5fe5702ef6e6)
